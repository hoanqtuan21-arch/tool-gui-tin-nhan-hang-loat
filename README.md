# tool-gui-tin-nhan-hang-loat

A simple Python tool to send bulk SMS messages.

## Usage

1. Install dependencies: `pip install -r requirements.txt`
2. Edit `main.py` to update API_KEY, NOI_DUNG (message content), and DANH_SACH_SDT (list of phone numbers).
3. Replace the placeholder API call with your actual SMS service API.
4. Run the script: `python main.py`

## Requirements

- Python 3.x
- requests library

## Note

This script is a template. Replace the API call with the actual endpoint from your SMS service provider.
